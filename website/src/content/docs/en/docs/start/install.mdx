<Tabs syncKey="os">
<TabItem label="macOS">

1. Download `ASIST-arm64.dmg` from [Releases](https://github.com/nyosegawa/asist/releases/latest).
2. Open the dmg and drag ASIST to the Applications folder.
3. Open ASIST from the Applications folder.

ASIST is notarized by Apple, so it opens as is. If macOS asks you to confirm that ASIST "is an app downloaded from the Internet", click "Open".

ASIST downloads new versions by itself and installs them the next time you quit it. See [Updating and uninstalling](/en/docs/start/update/) for details.

</TabItem>
<TabItem label="Windows">

1. Download `ASIST Setup <version>.exe` from [Releases](https://github.com/nyosegawa/asist/releases/latest).
2. Open the downloaded file.
3. If Windows says "Windows protected your PC", click "More info", then "Run anyway".
4. The installer installs ASIST and opens it. From then on, open ASIST from the Start menu.

The ASIST installer is not signed yet. Windows SmartScreen therefore warns about it, and shows the same warning each time you install a new version.

The installer does not ask for administrator rights. It installs ASIST for the current user only, into `%LOCALAPPDATA%\Programs\asist`. How to install a new version is covered in [Updating and uninstalling](/en/docs/start/update/).

<Aside type="caution">
ASIST cannot be installed on Windows with Smart App Control turned on, because it is not signed. You can check its state under "App & browser control" in Windows Security.
</Aside>

</TabItem>
</Tabs>

When it opens, the [first-time setup](/en/docs/start/setup/) begins.
