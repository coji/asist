title: Notes

A note is a document written in Markdown, and each note is one file. The list on the left shows the most recently updated notes first, and search looks through the text of the notes too. On the right, the Markdown is rendered (tables and checkboxes show as they are). Click "Edit" to change the Markdown itself, and press ⌘S (Ctrl+S on Windows) to save. Deleting goes through a confirmation screen and moves the file to the Trash on a Mac and to the Recycle Bin on Windows, so you can restore it from there while it is still in it.

The files are in `notes/` in the settings and data folder ([Where your data is kept](/en/docs/privacy/)). A note you change in another editor, or put into or delete from that folder in Finder or File Explorer, shows in the list right away, without restarting ASIST. A note you restore from the Trash or the Recycle Bin comes back to the list as well. Only files named the way ASIST names them, with the time the note was made and four characters from 0–9 and a–f, such as `20260923-153012-a1b2.md`, are notes; a file with any other name is not listed.

When a note you are editing is changed outside ASIST and you have not changed anything yet, the editor takes the new text. If you have unsaved edits, they stay, and you can't save until you choose "Load the new version" or "Overwrite with my edits". When a note you are editing is deleted outside ASIST, your unsaved edits stay in the editor, and saving keeps them as a new note.

In the conversation, "Take a note" writes a new note, and "Do I have a note about …?" finds one and reads it. You can't rewrite or delete an existing note from the conversation. Notes are not added to every conversation, and they are separate from memory.
