最初に開くと、9 つの画面を順に進みます。話し方に要らない画面は飛ばします。各画面の下に、次にやることが 1 行で出ます。

<Steps>

1. **言語を選ぶ**

   11 の言語から 1 つ選びます。最初に選ばれているのはシステムの言語です。選んだものが、画面の言語、会話の言語、地域の 3 つの初期値になり、ここから先の画面はその言語で出ます。3 つは、あとから設定で別々に変えられます。

   ![言語を選ぶ画面](/screens/ja/setup-1-language.webp)

2. **使う前に知っておくことを読む**

   答えが間違うことがあること、変更は承認してから行うこと、API の料金は提供元から請求されること、会話は選んだ提供元に送られることの 4 つが出ます。読んだら「4つの点を読んで理解しました」にチェックを入れて進みます。詳しくは[安全に使うために](/docs/privacy/safety/)にあります。この画面ができる前にセットアップを終えていた人には、次に開いたときに同じ内容が一度だけ出ます。

   ![使う前に知っておくことの画面](/screens/ja/setup-safety.webp)

3. **会話のモデルの API キーを入れる**

   提供元を選んで API キーを入れ、「検証して保存」を押します。キーは実際に問い合わせて確かめ、使えると分かったときだけ保存します。会話には、その提供元の標準のモデルを使い、つなぎの一言には、軽くて速いモデルを使います。どちらも、あとから設定で変えられます。

   ![API キーを検証して保存した画面](/screens/ja/setup-2-model.webp)

4. **話し方を選ぶ**

   「声で話す」「音声モデルとリアルタイムで話す」「文字で打ち、返事は声で聞く」「文字だけで使う」から選びます。

   「音声モデルとリアルタイムで話す」では、GPT-Live か Gemini Live が聞き取りと読み上げを受け持つので、聞き取りと読み上げの画面は飛ばします。GPT-Live には OpenAI、Gemini Live には Google の API キーが要ります。前の画面で同じ提供元のキーを検証していれば、そのエンジンが選ばれます。前に保存したキーや環境変数のキーがあれば、エンジンを選んだときにそのキーを検証するので、入れ直す必要はありません。キーがなければ、この画面でキーを入れて「検証して保存」を押します。声は提供元の標準のもので、あとから設定で変えられます。料金と違いは[声のエンジン](/docs/settings/voice-engine/)にあります。

   ![話し方で「声で話す」を選んだ画面](/screens/ja/setup-3-speaking.webp)

5. **聞き取りのモデルを準備する**(「声で話す」のとき)

   Mac では、搭載しているメモリに合わせて、Qwen3-ASR か、MLX で動く Whisper を勧めます。Windows では、NVIDIA の GPU のメモリに合わせて Qwen3-ASR 1.7B か 0.6B を勧め、初めての準備では CUDA 版 PyTorch の実行環境(約 2GB)もモデルと一緒に取得します。「モデルを準備する」を押すと、モデルを取得してこのコンピュータで動かします。ブラウザの中で動く Whisper も選べます。使える NVIDIA の GPU が無い Windows では、理由が出てモデルを選べないので、ブラウザの中で動く Whisper を選びます。

   ![おすすめのモデルの準備が終わった画面](/screens/ja/setup-4-listening.webp)

6. **読み上げを選ぶ**(「声で話す」か「文字で打ち、返事は声で聞く」のとき)

   会話の言語を話せるものだけが出ます。日本語なら、Mac では「macOS の音声合成」、Qwen3-TTS、VOICEVOX、AivisSpeech、Windows では「Windows の音声合成」、VOICEVOX、AivisSpeech です。Qwen3-TTS は Mac だけで、16GB 以上のメモリがあるときに選べます。モデル(約 1.9GB)を取得して、この Mac で動かします。OS の音声合成を選んだときは、その言語の声が入っているかを調べ、無ければシステム設定か Windows の設定のどこで足すかを案内します。

   ![読み上げの準備ができた画面](/screens/ja/setup-5-speech.webp)

7. **マイクを許可する**(「声で話す」か「音声モデルとリアルタイムで話す」のとき)

   「マイクを検証する」を押すと、実際に音を受け取れるかを確かめます。Mac では、その前に macOS が許可を求めるので「許可」を押します。Windows は許可を求めません。

   ![マイクを確かめた画面](/screens/ja/setup-6-microphone.webp)

   <Aside type="tip">
   許可しなかったときは、この画面からシステム設定か Windows の設定を開くか、文字で打つ使い方に切り替えられます。あとから許可するには、[マイクの許可](/docs/start/microphone/)を見てください。
   </Aside>

8. **ほかの準備を待つ**

   記憶の意味検索のモデルを準備します。日本語で「声で話す」を選んだときは、相槌の種類を判定するモデルと、話し終わりを判定する MaAI も準備します。MaAI は処理が重いので、準備だけしてオフにしておきます。使うときは、設定の「声」の「ターンテイキング(MaAI)」をオンにします。準備できなかったものは、やり直すか、あとに回せます。あとに回したものは、設定の「モデル」で準備します。

   ![ほかの準備が終わった画面](/screens/ja/setup-7-extras.webp)

9. **確かめて始める**

   選んだ内容を見て、「この内容で始める」を押します。

   ![選んだ内容の確認の画面](/screens/ja/setup-8-summary.webp)

</Steps>

始まったら、`MIC OFF` を押して話しかけるか、入力欄に文字を打って送ります。話しかけ方は[使い方](/docs/usage/)にあります。

Agent のジョブを使うなら、続けて [Agent の準備](/docs/start/agent-cli/)に進みます。
