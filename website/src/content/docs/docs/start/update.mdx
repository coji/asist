## 更新

ASIST は、開いたときと、開いているあいだ 6 時間ごとに、新しいバージョンが出ていないかを GitHub の Release に確かめます。新しいバージョンがあれば裏で取得し、次に ASIST を終了したときに入れ替えます。話している最中やジョブが動いている最中に、勝手に再起動することはありません。Mac でも Windows でも同じです。

すぐに入れ替えたいときは、設定の「このアプリについて」で「今すぐ再起動」を押します。今のバージョンと更新の状態も、ここに出ます。

Windows では、ウィンドウを閉じても ASIST は終了しません。タスクバーの通知領域にある ASIST のアイコンを右クリックして「終了」を押すと、インストーラーが画面を出さずに新しいバージョンを入れます。「今すぐ再起動」を押したときは、入れ終わると ASIST がまた開きます。`%APPDATA%\asist` の設定とデータは、そのまま残ります。

出したバージョンに問題があったときは、番号を上げて直したバージョンを出します。前のバージョンに戻す操作はありません。

## アンインストール

Google カレンダーにログインしているときは、アンインストールの前に、設定の「カレンダーとメール」で「ログアウト」を押します。Google への許可が取り消されます。

<Tabs syncKey="os">
<TabItem label="macOS">

1. ASIST を終了します。
2. 「アプリケーション」から ASIST をゴミ箱に入れます。
3. 設定とデータも消すときは、次のフォルダをゴミ箱に入れます。記憶、メモ、タスク、会話の履歴、取り込んだメールも消えます。
   - `~/Library/Application Support/asist/`
   - `~/Library/Logs/asist/`
   - `~/Library/Caches/asist-updater/`(自動更新で取得した新しいバージョンのファイル)
4. 保存した API キーとメールのパスワードの暗号化に使った鍵を消すときは、「キーチェーンアクセス」で「asist Safe Storage」を探して削除します。
5. マイクの許可も消すときは、ターミナルで次を実行します。以前の Mac 版でカレンダーを使っていたときは、2 行目でカレンダーの許可も消えます。

   ```bash
   tccutil reset Microphone com.nyosegawa.asist
   tccutil reset Calendar com.nyosegawa.asist
   ```

</TabItem>
<TabItem label="Windows">

1. タスクバーの通知領域にある ASIST のアイコンを右クリックし、「終了」を押します。
2. 「設定」→「アプリ」→「インストールされているアプリ」で ASIST の右の「…」を押し、「アンインストール」を押します。
3. 設定とデータも消すときは、`%APPDATA%\asist` のフォルダを消します。記憶、メモ、タスク、会話の履歴、取り込んだメール、動作ログも消えます。保存した API キーとメールのパスワードの暗号化に使った鍵も、このフォルダの中にあるので、一緒に消えます。
4. 自動更新で取得した新しいバージョンのファイルとインストーラーの控えは `%LOCALAPPDATA%\asist-updater` にあり、アンインストールでは消えません。これも消すときは、このフォルダを消します。

</TabItem>
</Tabs>

声の聞き取りと読み上げ(Irodori-TTS と Qwen3-TTS)のモデルは、設定とデータのフォルダの `speech-models/` にあり、設定とデータと一緒に消えます。以前のバージョンの ASIST が Hugging Face のキャッシュに取得したモデルは、上の手順では消えません。データとモデルの置き場所の一覧は、[データの置き場所](/docs/privacy/)にあります。
