## 更新

<Tabs syncKey="os">
<TabItem label="macOS">

ASIST は、開いたときと、開いているあいだ 6 時間ごとに、新しいバージョンが出ていないかを GitHub の Release に確かめます。新しいバージョンがあれば裏で取得し、次に ASIST を終了したときに入れ替えます。話している最中やジョブが動いている最中に、勝手に再起動することはありません。

すぐに入れ替えたいときは、設定の「このアプリについて」で「今すぐ再起動」を押します。今のバージョンと更新の状態も、ここに出ます。

</TabItem>
<TabItem label="Windows">

Windows 版の ASIST は、新しいバージョンを自分では取得しません。新しいバージョンが出たら、次のようにして入れます。

1. タスクバーの通知領域にある ASIST のアイコンを右クリックし、「終了」を押します。
2. [Releases](https://github.com/nyosegawa/asist/releases/latest) から新しい `ASIST Setup <バージョン>.exe` をダウンロードして開きます。SmartScreen の警告は、[インストール](/docs/start/install/)と同じように進めます。

前のバージョンの上に入れても、`%APPDATA%\asist` の設定とデータはそのまま残ります。

</TabItem>
</Tabs>

出したバージョンに問題があったときは、番号を上げて直したバージョンを出します。前のバージョンに戻す操作はありません。

## アンインストール

<Tabs syncKey="os">
<TabItem label="macOS">

1. ASIST を終了します。
2. 「アプリケーション」から ASIST をゴミ箱に入れます。
3. 設定とデータも消すときは、次のフォルダをゴミ箱に入れます。記憶、メモ、タスク、会話の履歴、取り込んだメールも消えます。
   - `~/Library/Application Support/asist/`
   - `~/Library/Logs/asist/`
4. 保存した API キーとメールのパスワードの暗号化に使った鍵を消すときは、「キーチェーンアクセス」で「asist Safe Storage」を探して削除します。
5. マイクとカレンダーの許可も消すときは、ターミナルで次を実行します。

   ```bash
   tccutil reset Microphone com.nyosegawa.asist
   tccutil reset Calendar com.nyosegawa.asist
   ```

</TabItem>
<TabItem label="Windows">

1. タスクバーの通知領域にある ASIST のアイコンを右クリックし、「終了」を押します。
2. 「設定」→「アプリ」→「インストールされているアプリ」で ASIST の右の「…」を押し、「アンインストール」を押します。
3. 設定とデータも消すときは、`%APPDATA%\asist` のフォルダを消します。記憶、メモ、タスク、会話の履歴、取り込んだメール、動作ログも消えます。保存した API キーとメールのパスワードの暗号化に使った鍵も、このフォルダの中にあるので、一緒に消えます。

</TabItem>
</Tabs>

声の聞き取りと読み上げのモデルは、ほかのアプリと共有する Hugging Face のキャッシュにあり、上の手順では消えません。データとモデルの置き場所の一覧は、[データの置き場所](/docs/privacy/)にあります。
