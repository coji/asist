Agent のジョブと、毎日の記憶の整理は、このコンピュータに入れた `codex` か `claude` の CLI を ASIST が子プロセスとして起動して行います。使うほうをインストールして、認証を済ませておきます。どちらを使うかは、設定の「Agent」で選びます。既定は codex です。

ASIST は CLI の認証情報に触れません。ASIST に保存した API キーは、環境変数にあるものも含めて CLI に渡しません。CLI で使う認証は、CLI の側で設定します。費用と利用枠は、CLI で認証したアカウントにかかります。

<Tabs>
  <TabItem label="codex">
    ChatGPT のアカウントでのサインインでも、API キーでも使えます。インストールと認証は、OpenAI の [Codex CLI の文書](https://developers.openai.com/codex/cli)に従います。

    ```bash
    codex login
    ```

    OpenAI の[非対話モードの文書](https://learn.chatgpt.com/docs/non-interactive-mode)は、保存したログインをスクリプトから使うことを前提にしています(2026-09-16 時点)。
  </TabItem>
  <TabItem label="claude">
    `ANTHROPIC_API_KEY` で動かします。インストールは Anthropic の [Claude Code の文書](https://code.claude.com/docs)に従い、CLI に API キーを設定します。

    <Aside type="caution">
    Claude.ai のサブスクリプション(Free、Pro、Max)でのサインインは、ASIST からは使えません。Anthropic の [Legal and compliance](https://code.claude.com/docs/en/legal-and-compliance) は、ほかのアプリが Claude.ai のログインで利用者の代わりに要求を送ることを認めていないからです(2026-09-22 時点)。
    </Aside>
  </TabItem>
</Tabs>

規約は変わります。業務で使う前には、上のページを確かめてください。

## Mac で使うとき

Mac では、ターミナルと同じ PATH で CLI を探し、その PATH で CLI を起動します。この PATH を読むために、ASIST はログインシェル(`$SHELL`)をターミナルを開いたときと同じ形で起動するので、`~/.zshrc` などのシェルの設定も読まれます。npm、nvm、bun、pnpm で入れた CLI も、ターミナルで動くならそのまま使えます。ASIST を起動したあとで CLI を入れたときは、設定を開くと探し直します。

シェルが 10 秒以内に PATH を返さなかったときは、シェルから PATH を読めなかったことを設定の「Agent」に表示し、ジョブを始めません。新しいターミナルを開いて、シェルの設定がエラーで止まったり、時間のかかる処理をしたりしていないかを確かめてください。

## Windows で使うとき

Windows では、CLI をそれぞれの公式のインストーラーで入れます。npm で入れた CLI は `.cmd` のファイルしか無いので、ASIST からは起動できません。npm で入れた CLI でジョブを始めようとすると、公式のインストーラーで入れ直すように案内が出ます。

codex は、Windows では codex 自身の Windows サンドボックスの中でだけ動かします。サンドボックスが無いと、書き込むジョブが作業場所の外にも書け、ネットワークにもつながってしまうためです。このサンドボックスには、管理者の権限で一度だけ行う準備が要ります。ターミナルで `codex` を一度起動し、表示に従って Windows サンドボックスを設定してください。準備が済むまでは、ASIST は codex のジョブを始めず、そのことを表示します。

claude は、Mac と同じように動きます。

ジョブの動きと確認画面は、[Agent のジョブ](/docs/apps/agent/)にあります。
