## 毎日の整理

記憶は、毎日 0 時に動く整理の Agent が、前日までの会話ログをもとに書きます。0 時にアプリが起動していなければ、次に起動したときに動きます。会話中でも裏で動き、画面にもジョブの一覧にも出ません。「覚えておいて」と話した内容も整理のときに反映し、「今の忘れて」と言われた話は書きません。整理の Agent は、その日に何をして、何を聞かれ、何を思ったかを一人称の日記に書き、人や場所のページには自分の印象を残します。

整理には codex か claude の CLI を使います([Agent の準備](/docs/start/agent-cli/))。設定の「記憶」で、整理の状態を確かめ、今すぐ実行できます。整理に失敗すると、その理由がここに出て、翌日の 0 時にやり直します。整理の途中でアプリを終了したときは失敗とはせず、次に起動したときにやり直します。やり直した整理も終わる前に終了したときは失敗とし、翌日の 0 時にやり直します。失敗した日の会話は、次の整理の対象に残ります。

## 会話に載るもの

毎回の会話には、「いつも覚えておくこと」(`instruction.md`)、「私について」(`me.md`)、「ユーザー」(`user.md`)の三つが丸ごと載ります。ASIST の人柄やあなたとの関係、あなたについての事実(たとえばアレルギー)が、どの会話でも効くようにするためです。三つとも整理の Agent が書き、記憶の画面で直すこともできます。「いつも覚えておくこと」を手で直した文は、次の整理でも残ります。ページと日記は、話したことに関係するものだけを検索して会話に添えます。検索は、文字の一致と、意味の近さ(multilingual-e5)を合わせて行います。

三つの文書には、それぞれ 1500 トークンまでという上限があります。毎回の会話で読まれるので、長くなるほど会話が重くなるからです。日本語ではおよそ 2000 字、英語ではおよそ 900 語です。整理の Agent は上限に収まるように書き、収まらない整理は取り込みません。上限ができる前から長い文書は、次の整理で短くなるまで、そのまま会話に載ります。

## 読む、直す

Dock の「記憶」で、すべての文書を読み、書き換えられます。左の一覧は「私とユーザー」「日記」「ページ」に分かれ、名前、別名、見出しで絞り込めます。本文は Markdown のファイルで、置き場は Git で履歴を取っています。保存は Git へのコミットになります。決まり(毎回の会話に載る三つの文書の長さ、ページと日記の見出しの下の長さ、一つのファイルで同じ見出しを二度使わないこと、ページの最初の「要約」の見出しなど)に合わない内容は保存せず、理由を表示します。上限を超えたときは、あとおよそ何字短くすればよいかも表示します。開いているあいだに整理が同じ文書を書き換えていたときも、上書きせずにそのことを表示します。編集を取り消すと、今の内容が表示されます。整理が文書を消していたときは、作り直さずにそのことを表示し、書いた内容は編集の画面に残します。消したページは、まだ整理していない日の会話に出てくると、次の整理で作り直されることがあります。
