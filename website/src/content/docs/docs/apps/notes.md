メモは Markdown で書く文書で、1 件が 1 つのファイルです。左の一覧は更新の新しい順に並び、検索は本文も対象にします。右では Markdown を整えて表示し(表やチェックボックスもそのまま見えます)、「編集」で元の Markdown を直して ⌘S(Windows では Ctrl+S)で保存します。削除は確認画面を通り、ファイルを Mac ではゴミ箱に、Windows ではごみ箱に移すので、そこに残っているあいだは元に戻せます。

メモのファイルは、設定とデータのフォルダの `notes/` にあります([データの置き場所](/docs/privacy/))。ほかのエディタで書き換えたメモや、Finder やエクスプローラーでこのフォルダに入れたメモ、消したメモも、ASIST を開き直さなくてもすぐに一覧に反映されます。ゴミ箱(Windows ではごみ箱)から元に戻したメモも、一覧にまた出ます。メモとして扱うのは、`20260923-153012-a1b2.md` のように、作った日時と、0〜9 と a〜f からなる 4 文字を ASIST が名前に付けたファイルだけで、ほかの名前のファイルは一覧に出ません。

編集しているメモが ASIST の外で書き換えられたとき、まだ何も書き換えていなければ、編集中の本文が新しい内容に置き換わります。保存していない編集があるときは、編集はそのまま残り、「新しい内容を読み込む」か「編集中の内容で上書き」を選ぶまで保存できません。編集しているメモが外で削除されたときは、保存していない編集がそのまま残り、保存すると新しいメモになります。

会話からは「メモして」で新しいメモを書き、「〜のメモあった?」で探して読みます。会話から既存のメモを書き換えることと消すことはできません。メモは毎回の会話に載らず、記憶とも別です。
