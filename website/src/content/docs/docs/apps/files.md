ファイルは、ファイルのカードで見ます。Markdown は文書として、CSV は表として、画像はそのまま、フォルダは中身の一覧として描きます。Word、Excel、PowerPoint、PDF、コード、JSON、Jupyter のノートブック、動画、音声も描けます。古い形式の Word、Excel、PowerPoint(.doc、.xls、.ppt)や zip のような描けない種類は、名前と大きさだけを出します。複数のファイルは一覧になり、押すと拡大表示でその項目を読めて、前後へ送れます。

中身の多いフォルダは、先頭の 200 件までを一覧にし、全部の件数を見出しに出します。残りは、Mac では「Finder で開く」、Windows では「エクスプローラーで開く」で見られます。

Word、Excel、PowerPoint、PDF と Jupyter のノートブックは、ファイル全体を読み込んでから描きます。大きなファイルを読むとアプリが止まるので、次の上限を超えるファイルは読まずに「大きいので、ここでは中身を出しません」と出します。中身は「Finder で開く」(Windows では「エクスプローラーで開く」)から、ふだん使うアプリで見てください。

| 種類 | 上限 |
| --- | ---: |
| Word | 16 MB |
| Excel | 8 MB |
| PowerPoint | 32 MB |
| PDF | 256 MB |
| Jupyter のノートブック | 512 KB |
| 音声の波形 | 8 MB |

音声は大きさにかかわらず再生できます。上限を超える音声は、波形を出さずに再生します。

HTML は、ページとして表示し、「ソース」で元の HTML に切り替えられます。ページのスクリプトは動きますが、読み込めるのは同じフォルダとその下にある CSS、画像、スクリプトだけで、外のサーバーからは何も読み込みません。ページはアプリから切り離した枠の中で動くので、アプリの画面や機能には触れられず、ほかのフォルダのファイルの中身も読めません。どのサーバーにも接続せず、フォームも送らず、ほかのサイトへ移ることもできません。ページの中のリンクはアプリの中では開かないので、開きたいときはそのファイルをブラウザで開いてください。

開けるのは、ジョブの作業場所、記憶のフォルダ、設定の「Agent」の「見せてよいフォルダ」の下だけです。
