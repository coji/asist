「見た目」で、画面全体のテーマを選び、画面の上に処理時間を出すかどうかを決めます。

![設定の「見た目」の画面](/screens/ja/settings-appearance.webp)

## テーマ

テーマは 4 つから選びます。選ぶとすぐに切り替わり、色、背景、カードの見出しが変わります。

| テーマ | 見た目 |
|---|---|
| フューチャー | 夜空と青いガラス。最初の見た目です。 |
| シンプル | 明るい白い壁 |
| ポップ | 明るい色と太い線 |
| クール | 暗いコンクリートの部屋 |

天気と時計のカードの絵は、どのテーマでも夜の景色のままです。

## 処理時間

「処理時間」の「画面の上に表示する」をオンにすると、直前の返事で各段階にかかった時間が画面の上に出ます。最初はオフです。

音声認識、返事の生成、読み上げにかかった時間と、話し終えてから返事の声が出るまでの時間(E2E)が分かります。声のエンジンが Gemini Live のときは、接続の状態、応答までの時間、セッションの分数、料金の見積もりが出ます。
