設定は、Dock の歯車のアイコンから開きます。左にページの一覧、右にそのページの項目が並びます。一覧は「概要」のあと、「アシスタント」「機能」「一般」の見出しで分かれています。ページの名前の下には、いまの設定が一行で出ます。使う設定なのにまだ動かないものがあるページは、その一行が警告の色になります。オフにしている機能は警告になりません。

## 概要

設定を開くと、最初に「概要」が出ます。

- 「今の構成」に、音声認識、会話のモデル、読み上げが並びます。押すと、そのページを開きます。
- 「準備が要るもの」に、使う設定になっているのにまだ動かないものが並びます。モデルの取得、Agent の CLI のインストール手順、API キーの登録など、直すための操作がその行にあります。
- 「追加できる機能」に、意味検索、ターンテイキング(MaAI)、ブラウザ内 Whisper のうち、オフのものが並びます。オフのままでも会話はできます。「準備してオンにする」を押すと、モデルを取得して、そのままオンにします。

![設定の「概要」の画面。今の構成と、準備が要るものが並んでいる](/screens/ja/settings-overview.webp)

モデルの取得は、そのモデルを使う項目の行でもできます。音声認識と読み上げは「声」、意味検索は「記憶」で準備します。取得の進み具合は、押したボタンの行に出ます。一度に取得できるのは 1 つだけです。

![設定の「声」の画面。音声認識のモデルの下に、まだ取得していないことと「準備する」が出ている](/screens/ja/settings-voice.webp)

## API の料金

「API の料金」には、会話のモデル、Gemini Live、Claude Code のジョブにかかった料金が日ごとに出ます。使った量と各社の公開価格(2026-09-23 時点)から ASIST が計算した目安で、実際の請求額と一致するとは限りません。Codex は金額を報告しないので含みません。音声認識と読み上げはこのコンピュータで動かすので、料金はかかりません。

## このアプリについて

最後のページ「このアプリについて」には、ASIST のバージョン、更新の状態、ライセンス、動作ログのフォルダ、使っているモデルと外部のデータの一覧が出ます。一覧の行には、提供元とライセンス、提供元のページへのリンクを並べています。新しいバージョンを取得し終えていれば、「今すぐ再起動」で入れ替えられます。Windows での更新は、[更新とアンインストール](/docs/start/update/)にあります。
