設定は、Dock の歯車のアイコンから開きます。左にページの一覧、右にそのページの項目が並びます。画面の言語は、右上で選びます。

## API の料金

「API の料金」には、会話のモデル、GPT-Live と Gemini Live、Claude Code のジョブにかかった料金が日ごとに出ます。使った量と各社の公開価格(2026-09-23 時点)から ASIST が計算した目安で、実際の請求額と一致するとは限りません。Codex は金額を報告しないので含みません。音声認識と読み上げはこのコンピュータで動かすので、料金はかかりません。

## このアプリについて

最後のページ「このアプリについて」には、ASIST のバージョン、更新の状態、ライセンス、使っているモデルと外部のデータの一覧が出ます。一覧の行には、提供元とライセンス、提供元のページへのリンクを並べています。新しいバージョンを取得し終えていれば、「今すぐ再起動」で入れ替えられます。Windows での更新は、[更新とアンインストール](/docs/start/update/)にあります。
