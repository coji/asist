「会話」の「声のエンジン」で、誰が聞いて話すかを選びます。既定は、このコンピュータの音声認識、会話のモデル、読み上げを組み合わせる構成です。

「このコンピュータの音声認識 + 会話モデル + 読み上げ」を選ぶと、その下に「音声認識」と「読み上げ」が準備できているかが出ます。初回の設定で GPT-Live か Gemini Live か「文字だけで使う」を選んだときは、音声認識と読み上げの準備を飛ばしています。音声認識は「モデル」で準備します。準備するまでマイクは使えません。「読み上げ」が「オフ」のときは、返事は文字だけで出ます。声で聞くには、「エンジンを選ぶ」から読み上げのエンジンを選びます。

GPT-Live か Gemini Live を選ぶと、マイクの音声をそのまま提供元に送り、提供元の声で話します。相槌、聞き取り、話し終わりと割り込みの判定はモデルが行い、このコンピュータの音声認識と読み上げ、つなぎの一言、MaAI は使いません。そのため、使える NVIDIA の GPU が無い Windows でも、声で話せます。エンジン、「モデル」、「声」、「会話が止まってから閉じるまで」のどれかを変えるとマイクがオフになるので、オンにし直します。

| エンジン | 判断とツール | 料金の目安 | 必要なキー |
|---|---|---|---|
| GPT-Live | GPT-Live が受け答えの間合いを受け持ち、中身は会話のモデルに任せます。会話のモデルの文を GPT-Live が自分の声で読みます。 | セッションが開いている時間で 1 分 $0.05 | OpenAI |
| Gemini Live | Gemini 自身が判断して ASIST のツールを呼びます。実行は ASIST が行うので、書き込みの確認画面はそのまま出ます。会話のモデルは使いません。 | 音声の入力 1 分 $0.005、出力 1 分 $0.018 | Google |

セッションは話し始めたときに開き、会話が止まって「会話が止まってから閉じるまで」(既定 90 秒)が過ぎると閉じます。閉じているあいだは課金されません。次に話しかけると、直前 3 秒の音声を溜めてから開き直すので、言い始めは欠けません。上の HUD に、接続、応答までの時間、セッションの分数、料金の見積もりが出ます。マイクをオフにすると、セッションを閉じます。

声は提供元が用意しているものから選び、「試聴」で同梱の見本を聞けます。試聴に API は使いません。

Gemini Live では、会話ログに、実際に聞こえた入力と出力の転写を書きます。GPT-Live では、会話のモデルに渡った発話と、会話のモデルが書いた返事を会話ログに書き、画面にもその返事を出します。GPT-Live は返事を自分の言葉に言い換えて読むので、聞こえる言い回しと画面の文は少し違うことがあります。挨拶や相槌のように GPT-Live が会話のモデルに渡さずに受け答えしたときは、あなたの言葉は次に会話のモデルに渡すときに一緒に渡してログに残し、GPT-Live 自身の言葉は残しません。ただし、「会話が止まってから閉じるまで」の時間より前に言った言葉と、マイクをオフにする前に言った言葉は渡しません。読み上げを途中で止めた返事は、全文が残ります。記憶の整理はこのログから行うので、エンジンを変えても同じ材料で動きます。
