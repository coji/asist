準備したモデルは、それぞれ専用のプロセスに常駐します。次の表は、Mac の M5(32GB)で、起動から 30 秒後に `vmmap --summary` の physical footprint を測った値です。

| プロセス | モデル | メモリ | 動く条件 | 測った日 |
|---|---|---|---|---|
| 音声認識 | Qwen3-ASR 1.7B 8bit(MLX) | 2.4GB | 起動したとき(音声認識が MLX のとき) | 2026-09-20 |
| 記憶の意味検索 | multilingual-e5 small(ONNX int8) | 655MB | 起動したとき(意味検索が有効のとき) | 2026-09-22 |
| 相槌の種類の判定 | ModernBERT-ja 70m(ONNX int8) | 325MB | 起動したとき(日本語で、相槌が有効で、Live のエンジンでないとき) | 2026-09-20 |
| 話し終わりの判定 | MaAI(PyTorch) | 685MB | マイクを入れたとき(日本語で、MaAI が有効のとき) | 2026-09-20 |

4 つが全部動くと、約 4.1GB です。Qwen3-TTS を読み上げに選ぶと、さらに約 2GB を使います。アプリの本体と画面は、それぞれ約 90MB です。

## Windows

Windows の音声認識は、NVIDIA の GPU のメモリにモデルを載せます。2026-09-27 に GeForce RTX 2080(8GB)で測った値は、Qwen3-ASR 1.7B が約 3.9GB、0.6B が約 1.6GB で、CUDA がこれとは別に約 0.5GB を使います。GPU のメモリが 6GB 以上なら 1.7B を、それより少なければ 0.6B を勧めるのはこのためです。

記憶の意味検索、相槌の種類の判定、話し終わりの判定は、Windows でも CPU とメインのメモリで動きます。Windows でのメモリの量は、まだ測っていません。
