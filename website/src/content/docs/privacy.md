このプライバシーポリシーは、Mac と Windows で動くデスクトップアプリ ASIST と、このサイト(asist-agent.com)が、利用者の情報をどう扱うかを説明します。

## 提供者と問い合わせ先

ASIST は、Sakasegawa が個人で開発し、オープンソース(MIT License)として無料で公開しています。

このポリシーやデータの扱いについての質問は、GitHub の [Issues](https://github.com/nyosegawa/asist/issues) で受け付けます。Issue は誰でも読めるので、個人の情報や予定の中身は書かないでください。

## ASIST のサーバーはありません

ASIST には、利用者のデータを受け取る ASIST 自身のサーバーがありません。ASIST の開発者は、アプリから利用者のデータを受け取りません。利用の統計も、不具合の報告も、アプリから自動で送ることはありません。

ASIST は、あなたが設定した外部のサービスに、あなたのコンピュータから直接つなぎます。何をどこへ送るかは、[外部のサービスへ送るもの](#外部のサービスへ送るもの)にまとめています。

## このコンピュータに置くもの

設定、会話ログ、記憶、メモ、タスク、取り込んだメール、API キーは、あなたのコンピュータの次のフォルダに置きます。アプリをアンインストールしても、これらのフォルダは残ります。消したいときは、フォルダごと削除してください。

| OS | 設定とデータ | 動作ログ |
|---|---|---|
| macOS | `~/Library/Application Support/asist/` | `~/Library/Logs/asist/` |
| Windows | `%APPDATA%\asist\` | `%APPDATA%\asist\logs\` |

- 設定で保存した API キーとメールのパスワードは、OS の仕組みで暗号化して保存し、平文では書きません。暗号化の鍵は、macOS ではキーチェーンに置き、Windows では DPAPI で Windows のユーザーに結び付けます。
- 会話ログには、あなたの発言、ASIST の返事、ツールの呼び出しと結果を、日ごとのファイルに書きます。設定の「会話」の「会話ログの保存日数」(既定では 90 日)を過ぎたファイルは、日付が変わるときに削除します。
- 記憶とメモは Markdown のファイルで、あなたが消すまで残ります。
- 動作ログには会話の本文を書きません。キー、トークン、パスワードの値は、書く前に伏せます。14 日を過ぎたファイルは削除します。

ファイルごとの中身は、[データの置き場所](/docs/privacy/)にあります。

## 外部のサービスへ送るもの

ASIST が外へ送るのは、次のサービスに、あなたが使う機能のために必要なものだけです。有料の API には、あなた自身の API キーでつなぎます。送ったデータは、それぞれのサービスの利用規約とプライバシーポリシーに従って扱われます。

| 送り先 | 送るもの | 送るとき |
|---|---|---|
| あなたが選んだ会話のモデルの提供元(Anthropic、OpenAI、Google、Cerebras) | 会話の文、プロンプト、記憶のうちその会話に関係する部分、ツールの結果 | 会話するたび |
| 提供元の組み込みの Web 検索(Anthropic、OpenAI、Google) | 会話のモデルが決めた検索の語 | 会話のモデルが検索するとき |
| OpenAI か Google の Live API | マイクの音声、直近の会話の履歴、ツールの結果 | 声のエンジンに GPT-Live か Gemini Live を選んだときだけ |
| codex か claude の CLI がつなぐサービス | ジョブのプロンプトと、CLI が読んだ作業フォルダの中身。記憶の整理では、前日までの会話(あなたの発言、ASIST の返事、ツールの名前と入力) | あなたが承認したジョブを実行するときと、毎日の記憶の整理のとき |
| 天気、世界時計、為替、ニュース、地図(気象庁、Open-Meteo、ExchangeRate-API、Google ニュース、Google の Maps Embed API) | 場所の名前や緯度と経度、通貨、話題の語、地図で探す場所や経路の語 | カードを表示するとき |
| あなたが設定したメールのサーバー(IMAP と SMTP) | ログインの情報、あなたが「送信」を押したメール、既読やアーカイブなどの操作 | メールを取り込むとき、送るとき、操作するとき |
| Google Calendar API | [Google のユーザーデータ](#google-のユーザーデータ)を見てください | Google カレンダーにつないだとき |
| Hugging Face、GitHub、PyPI など | 取得するファイルの要求と、ASIST とそのバージョンを示す User-Agent | このコンピュータで動かすモデル、Python、ASIST の新しいバージョンを取得するとき |

声の聞き取り、声の区間の検出、相槌の判定、記憶の検索は、このコンピュータの中だけで動き、音声も文も外へ送りません。VOICEVOX、AivisSpeech、Qwen3-TTS による読み上げも、このコンピュータの中で動きます。

送り先ごとの詳しい一覧は、[外へ送るもの](/docs/privacy/external/)にあります。

## Google のユーザーデータ

ここでは、ASIST を Google カレンダーにつないだときに、Google から受け取るデータをどう扱うかを説明します。いまの Mac 版の ASIST は macOS のカレンダーを読み、Google には直接つなぎません。

### 求める権限と使いみち

- `https://www.googleapis.com/auth/calendar.calendarlist.readonly`

  あなたの予定表の一覧とその色を読みます。どの予定表を表示し、新しい予定をどの予定表に保存するかを、あなたが選べるようにするためです。予定表の一覧は変更しません。

- `https://www.googleapis.com/auth/calendar.events`

  予定を読み、カレンダーの画面と会話で見せます。あなたが頼んだときに、予定を作成、変更、削除します。書き込みは、会話から頼んだときも画面で操作したときも、ASIST が内容を確認画面に出し、あなたが承認してから実行します。

### 保存する場所

予定は、あなたのコンピュータで動く ASIST が Google から直接読み、このコンピュータの中で使います。ASIST の開発者や、ASIST のサーバーに送ることはありません。Google へのログインの情報(トークン)は、API キーと同じように OS の仕組みで暗号化して、このコンピュータに保存します。

### ほかのサービスに渡すとき

あなたが会話で予定について聞いたり、予定の追加や変更を頼んだりすると、その答えに必要な予定を、その会話の一部として、あなたが選んだ会話のモデルの提供元に送ります。声のエンジンに GPT-Live か Gemini Live を選んでいるときは、その Live API にも送ります。送るのは、あなたに答えるためだけです。

予定について話した内容は、ほかの会話と同じように、このコンピュータの会話ログに残ります。毎日の記憶の整理では、前日までの会話ログのうち、あなたの発言、ASIST の返事、ツールの名前と入力を、あなたが使う codex か claude の CLI に渡し、その結果をこのコンピュータの記憶に書きます。

これ以外に、Google から受け取ったデータをほかの人やサービスに渡すことはありません。

### しないこと

- Google から受け取ったデータを売りません。
- 広告に使いません。広告のために、ほかの人やサービスに渡すこともしません。
- 汎用の AI や機械学習のモデルを開発、改善、学習するために使いません。
- ASIST の開発者を含め、人がこのデータを読むことはありません。ASIST の開発者は、このデータを受け取りません。

Google API から受け取った情報の ASIST による使用と、ほかのアプリへの転送は、限定使用の要件を含む [Google API サービスのユーザーデータに関するポリシー](https://developers.google.com/terms/api-services-user-data-policy)に従います。

### アクセスを取り消す

- ASIST で Google からログアウトすると、ASIST はこのコンピュータに保存したログインの情報を削除し、Google カレンダーを読まなくなります。
- Google の側でも、いつでもアクセスを取り消せます。Google アカウントの「セキュリティ」で、サードパーティ製のアプリとの接続([myaccount.google.com/connections](https://myaccount.google.com/connections))を開き、ASIST を選んでアクセスを削除します。

## このサイト

このサイト(asist-agent.com)は、訪問の数を数えるために、Cookie を使う Google Analytics を使っています。Google Analytics が集めるデータの扱いは、[Google によるデータの使用](https://policies.google.com/technologies/partner-sites?hl=ja)にあります。サイトは Cloudflare から配信しています。このサイトには、入力して送るフォームやアカウントはありません。

## 子ども

ASIST は、13 歳未満の子どもに向けて作ったものではありません。ASIST の開発者は、年齢にかかわらず、利用者の情報を集めません。ASIST がつなぐ外部のサービスには、それぞれの利用規約に年齢の条件があります。

## ソースコード

ASIST はオープンソースで、ソースコードは [GitHub](https://github.com/nyosegawa/asist) で公開しています。このポリシーに書いたことを、ASIST が実際にどう行っているかは、ソースコードで確かめられます。
