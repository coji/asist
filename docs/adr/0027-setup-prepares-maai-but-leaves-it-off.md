# 初回セットアップは MaAI を準備するだけで、オンにするのは利用者に任せる

日本語で声で話す人の初回セットアップでは、MaAI のモデルを取得して準備しておくが、ターンテイキングの設定はオフのままにする。使いたい人が「声」の画面でオンにする。MaAI は会話のあいだ CPU で動き続けるので、Apple M2 のようなマシンでは Qwen3-TTS と CPU を取り合い、読み上げの声が途切れる。MaAI が無くても会話はできるが、声が途切れると会話が聞き取りにくくなる。準備まで済ませておけば、スイッチを入れるだけで使えるので、245MB の取得は初回セットアップで済ませる。

## 見送った案

- **初回セットアップで準備もしない。** 使いたくなったときに、設定の「モデル」で取得を待つことになる。
- **速いマシンでだけオンにする。** どのマシンから取り合いが起きないかは、測って線を引く必要がある。

## 実測

2026-09-28、M2 16GB の Mac で、Qwen3-TTS を単独で動かすと、1秒分の声を作るのに 0.53〜0.54 秒かかり、再生は途切れなかった。アプリの中で MaAI と一緒に動かすと、MaAI の処理の速さの比が 1.27〜1.55 まで上がり、読み上げが途切れた。MaAI をオフにすると途切れなくなった。

## 分かっている制約

- すでに MaAI をオンにしている利用者の設定は変えない。
