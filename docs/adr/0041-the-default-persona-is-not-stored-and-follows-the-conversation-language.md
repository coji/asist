# キャラクターが既定のあいだは文章を保存せず、会話の言語で読む

設定の「キャラクター」が既定のあいだ、settings.json には文章を書かず、既定であることだけを保存する。会話のプロンプト、設定の画面、記憶の整理は、読むたびにそのときの会話の言語で既定の文章を取り出す(`personaText`)。利用者が書いた文章は書いたまま保存し、会話の言語を変えても変えない。既定の文章をそのまま設定に保存すると、会話の言語を変えるたびにその文章を書き換える必要があり、書き換えない画面から言語を変えた人は、前の言語のキャラクターで話し続けることになるからである。この形なら、既定の文章を直したときも、自分で書いていない人全員にそのまま届く。

## 見送った案

- **既定の文章を保存しておき、会話の言語を変えるときに既定と同じなら書き換える。** 言語を変える場所ごとに書き換えが要り、1 つでも漏れると前の言語のキャラクターが残る。また、既定かどうかを文章を比べて決めるので、既定の文章を直すと、それまでの既定の文章が利用者の書いたものとして扱われる。
