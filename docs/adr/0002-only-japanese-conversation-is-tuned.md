# 会話は日本語だけを作り込み、ほかの10言語は共通の作りで動かす

相槌、発話の終わりを見分ける MaAI、VOICEVOX と AivisSpeech と Irodori-TTS、手で調整したプロンプト、Whisper が無音から作り出す文句の一覧は、どれも日本語で測って調整してきた。日本語の会話はこの作りをそのまま使う。ほかの10言語は言語ごとの作り込みをせず、英語で書いた1組のプロンプトの中で「ユーザーは○○語で話す」と会話の言語を名指しし、相槌と MaAI は動かさず、発話の終わりは設定の固定の待ち時間だけで決める。相槌の頻度や間の取り方は言語によって大きく違い、日本語で測った調子をそのまま移すと不自然になるからである。日本語でも、ほとんどのターンはこの待ち時間で区切られている。

日本語にしかない機能は、ほかの言語では起動せず、モデルも取得せず、設定画面にも出さない。使えない項目を無効の状態で見せることもしない。その言語に無いものは、画面にも無いほうが分かりやすいからである。どの機能がどの言語にあるかは `conversationFeatures(locale)` の1か所で決める。

## 見送った案

- **日本語の相槌と MaAI をほかの言語でも動かす。** 上に書いたとおり不自然になる。

## 分かっている制約

- 日本語と英語以外の言語では、会話を通して動かして確かめていない。英語と同じ経路を通ることを、テストで確かめているだけである。
- 日本語以外の文の区切りには `Intl.Segmenter` を使う。小数は切らないが、略語を見分けられないので、ドイツ語の「z. B.」は2つの文に分かれる。
- Whisper が無音から作り出す文句の一覧は日本語のものしかない。ほかの言語の一覧は、実際の誤りが集まってから足す。
- 読み上げは OS の声と Qwen3-TTS から選ぶ。Qwen3-TTS はヒンディー語とインドネシア語を話せないので、この2つは OS の声だけになる。
