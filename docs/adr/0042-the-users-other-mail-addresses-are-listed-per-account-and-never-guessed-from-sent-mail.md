# 自分のメールアドレスは、アカウントのアドレスと設定に書いたアドレスだけにし、送信済みのメールから推測しない

メールのアカウントごとに、設定に「ほかに送信に使っているアドレス」の欄を置き、アカウントのアドレスとそこに書いたアドレスだけを自分のアドレスとして扱う(`isOwnAddress`)。自分が送ったメールへの返信の宛先、「全員に返信」で宛先から外すアドレス、会話のモデルに伝える自分のアドレスは、すべてここから決める。欄が空のアカウントは、アカウントのアドレスだけが自分のアドレスになる。Gmail の送信元アドレスのように、利用者がアカウントのアドレスとは別のアドレスから送ることはあるが、どれが自分のアドレスかを ASIST がメールから確かめる手段はないので、利用者に書いてもらう。

## 見送った案

- **送信済みフォルダにあるメールの差出人を、すべて自分のアドレスとみなす。** 上司の代わりに上司のアドレスで送ったメールがあると、上司が自分として扱われ、そのメールへの返信の宛先から上司が落ちる。

## 分かっている制約

- ここに書いたアドレスは、自分のアドレスを見分けるためだけに使う。新しいメールも返信も、差出人はいつもアカウントのアドレスで、ここに書いたアドレスからは送れない。会話のモデルにもそう伝えている。
