# 設定は概要から開き、モデルの準備はそのモデルを使う項目の行で行う

設定の画面は「概要」から開く。概要には、音声認識、会話のモデル、読み上げの今の構成と、使う設定になっているのにまだ動かないもの、オフのまま追加できる機能を並べる。モデルや実行環境の取得は、準備だけを集めたページを作らず、そのモデルを選んだりオンにしたりする行で行う。音声認識は「声」の音声認識の行、意味検索は「記憶」の意味検索の行で準備する。左の一覧と概要が警告するのは、使う設定になっていて動かないものだけで、オフにしている機能は数えない。選ぶ場所と準備する場所が分かれていると、ページを行き来することになる。オフの機能まで「未準備」と数えると、何もしなくても警告が消えなくなる。

## 見送った案

- **準備を「モデル」のページにまとめる。** 以前の形。音声認識を「声」で選んで「モデル」で取得するように、選ぶ場所と準備する場所が分かれ、「「モデル」を開く」のリンクで何度も行き来することになった。
- **概要を置かず、「会話」のページから開く。** ページの分け方は同じでも、今の構成と足りないものを見るには、ページを一つずつ開くことになる。
- **全部のページを1枚に並べ、検索で絞る。** ページがとても長くなる。検索は、ライセンスの一覧のように設定と関係の無い行まで拾う。
