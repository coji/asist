# MaAI を起動できないときは、設定した無音の長さで会話を続け、そのことを一度だけ知らせる

「声」の画面で MaAI をオンにしているのに、マイクをオンにしたときに MaAI の worker を起動できなかったら(Python 環境やモデルが無い、worker が終了した、読み込みが時間内に終わらない)、マイクは止めずに、設定した無音の長さで話し終わりを判断して会話を続ける。原因は main のログに書き、利用者には、MaAI をオンにしてから最初の一度だけ、MaAI を起動できず設定した無音の長さで判断していることを知らせる。ASIST は失敗を隠して別の動きに切り替えないことにしているが、これはその例外である。MaAI は話し終わりの判断を速くするためのもので、無くても会話はできる。MaAI のためにマイクを止めると、会話そのものができなくなる。一方で、知らせずに切り替えると、利用者は MaAI が動いていると思ったまま、返事が遅いことの理由が分からない。

## 見送った案

- **マイクをオンにする操作ごと失敗させる。** MaAI を直すか、設定でオフにするまで、会話ができなくなる。

## 分かっている制約

- 会話の途中で worker が終了し、起動し直せなかったときは、ログに書くだけで、その場では知らせない。次にマイクをオンにしたときの起動も失敗すれば、まだ知らせていない場合に限って知らせる。
- MaAI がオフのとき、日本語以外で会話しているときは、起動しないので何も知らせない。
