# VAD は「はい」ひとつの返事も音声認識に送り、エネルギー判定の固定の下限は下げない

VAD のエネルギー判定の固定の下限(RMS 0.012、約 −38 dBFS)は変えない。音声認識に送る最低の長さは、声の区間を 100 ms、そのうち Silero が声と認めた時間を 30 ms に下げる。実際に使うときの入力には、asist-mic(macOS の音声処理)でも getUserMedia でも自動ゲインがかかるので、声は下限より 10 dB 以上大きく届く。捨てられていたのは小さい声ではなく、「はい」「うん」のような短い返事だった。短い返事は、声の区間も Silero が声と認める時間も短く、以前の最低の長さ(250 ms と 150 ms)に届かなかった。ところが、長さを短い返事に合わせると、咳払いや咳も同じくらいの長さで Silero に声と認められることがあり、音声認識はそれを「うん。」と書き起こす。長さでは両者を分けられないので、咳払いで要らない返事が返ることを受け入れて、短い返事を通す。音声で承認できる操作はないので、起きるのは返事が1回増えることだけである。キーを打つ音、机をたたく音、物を置く音は、Silero が声と認めないので、この値でも通らない。途中の書き起こしと、話している途中の相づちは、これまでどおり Silero が 150 ms を声と認めてから始める。

## 見送った案

- **固定の下限を下げる。** 自動ゲインのない録音では、声が下限を 3〜6 dB しか上回っておらず、下げる必要があるように見えた。しかし実際の入力では、声は十分大きく届いていた。下げると asist-mic では、読み上げのエコーや部屋の小さな音で取り込みが始まる回数が増え、そのたびに読み上げの音量が下がる。
- **最低の長さを今のままにする。** 「はい」だけの返事が、測った4通りのうち3通りで捨てられる。
- **アシスタントが質問した直後だけ、短い返事を受ける。** 質問かどうかを見分ける仕組みが要る。しかも、咳払いの「うん」が質問への答えとして扱われる危うさは、まさにその時間に集まる。

## 実測

2026-09-30、MacBook Pro(Apple M5、macOS 26.2)、ASIST 0.3.1、本人の声。内蔵マイクと Bluetooth のイヤホンを、それぞれ asist-mic と getUserMedia で使った4通りで測った。VAD に入る直前の音声と、フレームごとの判定の状態を記録し、同じフレームに値を当てはめ直した。ASIST の値で当てはめ直した判定は、4通りのすべての項目で ASIST 自身の判定と一致した。

- 普通の声は −12〜−28 dBFS で届いた(声のフレームの 95 パーセンタイル)。小さい声は −15〜−26 dBFS、内蔵マイクから 1m 離れた声は −17〜−19 dBFS だった。
- 同じ文を自動ゲインなしで録った録音より、12〜19 dB 大きかった。その録音31本を測った音量に合わせて VAD に通すと、以前の値で捨てられるのは「はい」の1本だけで、さらに 12 dB 下げても変わらなかった。新しい値では31本とも通った。
- 部屋の音は、asist-mic では −100 dBFS より小さく、getUserMedia の内蔵マイクでは −68 dBFS だった。asist-mic で届いたアシスタントの声のエコーは、内蔵マイクで大きいところ −36 dBFS だった。
- 以前の値で捨てられた普通の声の「はい」「うん」は、声の区間が 128〜320 ms、Silero が声と認めた時間が 43〜192 ms だった。
- 物音で Silero が声と認めた時間は、キー、机、コップがどれも 0 ms、咳が 0〜85 ms、咳払いが 0〜384 ms だった。咳払いは、以前の値でも1回「うん。」として会話になった。
- 新しい値で新しく音声認識に送られるのは、次のものだった。書き起こしは ASIST と同じ Qwen3-ASR 1.7B で行った。
  - 捨てられていた「はい」「うん」と長めの発話が9つ。1つの「うん」は「です。」と書き起こされた。
  - ASIST に向けずに話した会話が1つ。
  - 咳と咳払いが1つずつ。どちらも「うん。」と書き起こされた。
- 新しい長さのうえで固定の下限を −42 dBFS に下げると、Bluetooth の小さい声の「はい」と、getUserMedia での割り込みが1つずつ新しく通った。一方で、内蔵マイクの asist-mic では、1回の測定のあいだに取り込みの開始が3回増えた。−48 dBFS まで下げると、この開始は12回増えた。

## 分かっている制約

- 咳払いや咳が「うん。」として会話になり、要らない返事が返ることがある。
- 測ったのは Mac だけで、Windows の取り込みは測っていない。
