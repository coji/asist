# YouTube と X に投稿する紹介動画

ASIST を紹介する最初の動画と、YouTube のサムネイルです。動画は 48 秒、1920×1080、30fps で、H.264 と AAC で書き出します。絵と動きは HTML と GSAP で作り、headless Chrome で 1 コマずつ撮ります。できた動画とサムネイルは `out/` に書き出し、コミットしません。

```bash
npm run promo:video       # out/asist-launch-video.mp4 ができます(10 コアの Mac で 7 分ほど)
npm run promo:thumbnail   # out/youtube-thumbnail.png ができます(1280×720)
```

Google Chrome、ffmpeg、[uv](https://docs.astral.sh/uv/) が要ります。見出しの書体は Google Fonts から読み込むので、ネットワークにつながっている必要があります。

## 動画の作り方

`npm run promo:video` は、次の 3 つを順に実行します。途中の段だけをやり直すこともできます。

1. `node scripts/render.mjs` が、`index.html` のタイムラインを進めながら画面を撮り、音のない `out/video.mp4` を作ります。効果音を鳴らす時刻と、曲を飛ばす位置は `out/cues.json` に書き出します。
2. `uv run scripts/audio.py` が、BGM を途中で飛ばしてつなぎ、効果音を重ねて `out/audio.wav` を作ります。
3. `sh scripts/encode.sh` が、画と音をまとめて `out/asist-launch-video.mp4` を作ります。YouTube と X が受け付ける形(H.264 High、BT.709、AAC、先頭にインデックス)で、音量は -20 LUFS です。

`render.mjs` は headless Chrome をいくつか立ち上げ、それぞれに動画の一部を受け持たせます。各 Chrome は撮った JPEG をそのまま ffmpeg に渡すので、途中のコマはディスクに書きません。主なオプションは次のとおりです。

| オプション | 働き |
|---|---|
| `--mb 1` | モーションブラーなしで速く書き出します(既定は 16) |
| `--workers 4` | 同時に動かす Chrome の数(既定は CPU の数より 2 少ない数) |
| `--from 8 --to 16` | その秒の範囲だけを `out/part-8-16.mp4` に書き出します |
| `--stills 3.5 14.5` | その時刻の静止画を `out/stills/` に書き出します |

ブラウザーで `index.html#t=12.5` を開くとその秒で止まり、`index.html#play` を開くと音なしで通して再生します。

速く動くものがにじんで見えるように、1 コマの時間のうちシャッターが開いている半分(シャッター角 180°)に画面を 16 回撮り、ffmpeg の tmix で平均しています。6 回では、速いカメラの動きで像が段になって見えました。

## 場面

曲のテンポ(106 BPM)に合わせて、場面の切り替えと、ものが出てくる時刻を拍にそろえています。`js/core.js` の `B(n)` が n 拍目の秒を返します。曲は 3 拍の弱起で始まるので、小節の頭は 3 拍目(1.83 秒)からです。

| 秒 | 拍 | 場面 | 前の場面からの移り方 |
|---|---|---|---|
| 0–4.4 | 0–7 | 「ねぇ ASIST、今日の予定は?」に、ロボットが跳んできて予定のカードで答える | |
| 4.0–9.0 | 7–15 | 見出し「話しかけるだけで、予定もメールも片づく。」 | カードから青い円が広がる |
| 8.4–15.8 | 15–27 | カード。2 拍ごとの 3 つの質問に 1 枚ずつカードが答え、最後に 8 枚が 3D の輪になって回る | 見出しが上へ抜け、下から入る |
| 15.4–20.1 | 27–35 | 実際のアプリの画面。最後に Dock へ寄る | 輪のカードが外へ散り、中央から画面が回り込む |
| 19.9–27.0 | 35–47 | ミニアプリ。Dock に手書きのラベルが付き、「カレンダーで来週を開いて」でカレンダーが開く | 画面の Dock がそのまま大きな Dock になる |
| 26.6–33.8 | 47–59 | Agent。依頼、承認、codex か claude への引き渡し、完了 | Agent のアイコンから円が広がる |
| 33.2–38.3 | 59–67 | 記憶。夜 0 時に、雲の上のロボットが日記を書く | 夜が波の形で上から下りる |
| 37.8–40.3 | 67–71 | 11 の言語 | 朝が波の形で下から上がる |
| 40.3–47.9 | 71– | 「さあ、はじめましょう。」とサイトの URL | 3 本の帯が横切る |

場面ごとに `js/` のファイルが 1 つあり、場面の始まりからの拍で時刻を書いています(`b(k)` が、場面の始まりから k 拍あとの秒です)。場面の長さを変えるときは、ファイルの先頭の `S` と、次の場面の `S` を動かします。曲は 35 拍目で 16 拍先へ飛ぶので(「BGM」の節)、そのあとの拍の数は曲の拍の数より 16 少なくなります。曲は動画の 40.3 秒(71 拍目)からテンポが落ちて最後の和音へ向かうので、最後の場面だけは、`tools/ending.py` で曲から測った音の立ち上がりの秒に合わせています。曲の秒を動画の秒に直すのは `js/core.js` の `M()` です。

共通の道具(拍、カメラ、ポップ、はじけるリング、紙吹雪、波のワイプなど)は `js/core.js` にあります。場面の中の層に `data-depth` を付けておくと、カメラを動かしたときに奥の層ほど少なく動くので、横に振ったり寄ったりしたときに奥行きが出ます。画面に出るものはすべてタイムラインの時刻だけで決まり、紙吹雪や星のまたたきも乱数の種を固定して時刻から位置を計算するので、どのコマから書き出しても同じ絵になります。

## サムネイル

`thumbnail.html` が YouTube のサムネイルです。サイトの OG 画像の絵(`website/og/art.png`)に、ロゴと見出しを重ねています。`npm run promo:thumbnail` が headless Chrome で 1280×720 の PNG に書き出します。YouTube はサムネイルを 2 MB までしか受け付けないので、それより大きくなったときは書き出しを止めます。

## 素材

アイコン、カード、イラスト、アプリの画面は、`website/public/` のものを参照しています。

`assets/gen/` は、この動画のために OpenAI Images API(gpt-image-2.5-flare)で作った素材です。既存のイラストを参照に渡し、同じフェルトとクレイの質感にしています。

| 場所 | 中身 |
|---|---|
| `chars/` | ロボットの 4 つのポーズ(手を振る、跳ぶ、差し出す、日記を書く)と、話しかける女の子 |
| `props/` | 24 個の小物(カレンダー、封筒、太陽、雲、雨雲、コイン、チェック、月、星、日記帳、時計、鉛筆、地球儀、書類、吹き出し、ターミナル、ピン、ストップウォッチ、新聞、きらめき、マイク) |
| `prompts/` | 生成に使ったプロンプト |

作り直すときは、次の順に進めます。

1. `uv run tools/refs.py` が、参照に渡す画像を `assets/gen/refs/` に作ります。サイトの絵から切り出したロボットと女の子、紙の色に置いたヒーローの絵、6 つの枠を描いたテンプレートです。
2. `prompts/` のプロンプトと `refs/` の画像を Images API に渡し、背景を透過して生成した画像を `assets/gen/raw/` に置きます。ロボットのポーズは `ref-robot-cta.png` と `ref-hero-flat.png` を、女の子は `ref-girl-cta.png` と `ref-hero-flat.png` を渡して 1024×1024 で、小物のシートは `ref-hero-flat.png` を渡して 2048×1536 で作りました。`sheet-extra` のように、先頭に `frame-3x2.png` を渡すと、小物が枠の中に 1 つずつ収まります。
3. `uv run tools/cutout.py` が、シートから小物を 1 つずつ切り出し、キャラクターの余白を切って、`props/` と `chars/` に WebP で書き出します。

`raw/` と `refs/` は大きいので、コミットしていません。透過で生成すると、小物のまわりに白いもや(アルファが 50〜110 ほどの部分)が付くことがあり、暗い背景では光って見えます。`cutout.py` は、アルファの低い部分を削り、縁の色を内側の色で置き換えています。

## BGM

`assets/bgm/musicbox.mp3` は、Gemini API の Lyria 3.5 で作ったオルゴールの曲です。`python3 scripts/bgm.py musicbox` で作り直せます。API キーは環境変数 `GEMINI_API_KEY` か `~/.config/gemini/api_key` から読み、料金は 1 曲 $0.08 です。生成した音声には、Google の SynthID の透かしが入っています。

曲は 58 秒ありますが、動画では 35 拍目(19.97 秒)で 16 拍先の 51 拍目へ飛ばして、48 秒にしています。50 秒に近い 12 拍では、どの位置で飛ばしても和音の似ている度合いが 0.82 以下で、つなぎ目が聞こえます。飛ばす位置は、前後の和音がそろい、場面が Dock へ寄って切り替わる 35 拍目です(`tools/splice.py` で調べた和音の似ている度合いは、つなぎ目の前が 0.99、後が 0.95)。`scripts/audio.py` は、つなぎ目の前後で音の立ち上がりをそろえてから 40 ms で重ねてつなぎます。2 つの立ち上がりの間は拍で数えた 16 拍より 5 ms 長いだけなので、動画の側はちょうど 16 拍ずらしています。飛ばす位置と拍の数は `js/core.js` の `MUSIC` で決め、`render.mjs` が `out/cues.json` に書き、`audio.py` がそれを読みます。動画の終わりは、曲の最後の和音が消えるところ(曲の 57 秒)に合わせています。

## 効果音

効果音は `scripts/sfx.py` が numpy で合成します。画面で起きる出来事を 11 種類に分け、それぞれにオルゴール(`musicbox`)、クレイ(`clay`)、Mac の画面(`mac`)の 3 通りの音を用意し、動画ではクレイの音を使います。クレイには、この動画のための音(跳ぶ、着地する、飛ぶ、開く、閉じる、完了、時計、朝、URL)があります。見出しの文字、カードの種類の名前、言語の数のように、短い間にいくつも続くものには、曲と同じ F メジャーのペンタトニックでカリンバの音が上がっていく音(`chime`)を当てています。Dock のラベルは 8 分音符ごとに 1 つずつ出るので、オルゴールのパターンのカリンバを、ラベルごとに 1 音ずつ鳴らします。`uv run scripts/sfx.py` を実行すると、すべての音を 1 つずつ `out/sfx/` に書き出します。

どの出来事にどの音を当てるかは `scripts/audio.py` の `KIND` にあります。カーソルの移動、バッジ、最後の紙吹雪では音を鳴らしません。`--sfx-db` で効果音全体の音量を変えられます。効果音は曲より 20 dB ほど小さく鳴ります。

## 道具

| ファイル | 働き |
|---|---|
| `tools/beats.py`、`tools/downbeat.py` | 曲のテンポと拍の位置、小節の頭を測ります |
| `tools/ending.py` | 曲の終わりの、テンポが落ちていく部分の音の立ち上がりを並べます |
| `tools/splice.py` | 曲を飛ばせる位置を、和音の似ている度合いで比べます |
| `tools/refs.py`、`tools/cutout.py` | 生成に渡す参照の画像を作り、生成した画像から素材を切り出します |
| `tools/sheet.py` | `out/stills/` の静止画を 1 枚の一覧にまとめます |
| `tools/review.py` | 書き出した動画を、決まった間隔のコマの一覧にします |
